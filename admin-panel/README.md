# Admin Panel

React-based admin panel for controlling Ludo game clients.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Admin panel will start on http://localhost:3000

## Build

```bash
npm run build
```

## Features

- View connected Android clients
- Send roll commands to clients
- Force specific dice values (hidden from players)
- Real-time client connection status

## Configuration

Edit WebSocket server URL in the connection panel (default: ws://localhost:8080)
